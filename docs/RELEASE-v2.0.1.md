# VEIL 2.0.1 — AmneziaWG 3.1 / Windows x64

Новый Windows-клиент с транспортом AmneziaWG 3.1 и раздельной маршрутизацией по приложениям, доменам и IP. Остальной трафик направляется через исходный сетевой интерфейс.

## Что изменилось

- Полностью новый нативный интерфейс Qt: обзор подключения, маршрутизация с поиском, настройки и журнал событий.
- Короткие анимации переключателей и подсветка кнопок; настройка уменьшения анимаций.
- Экраны не пересоздаются при переходах, сетевые операции выполняются в фоне. Анимация индикатора останавливается в свёрнутом окне.
- Импорт AWG 3.1 .conf и vpn:// с вложенным AWG-профилем. Ключи хранятся с защитой Windows DPAPI и скрыты в журнале.
- Реальные счётчики трафика AWG и HTTPS-проверки отклика. HTTPS-отклик включает TCP/TLS/HTTP и не является игровым ping.
- Исправлены кодировка кириллических имён сетевых интерфейсов, выбор исходного подключения, повторный захват внешнего AWG-трафика и конфликт ICU DLL при упаковке Qt.
- Ограничены очереди и размер журнала, добавлены отмена загрузки списков и очистка дочернего маршрутизатора при аварийном завершении клиента.

## Установка

1. Скачайте **VEIL-2.0.1-windows-x64.zip** и распакуйте всю папку **VEIL**.
2. Завершите старую версию через **трей → Выход**.
3. Запустите **VEIL.exe**. Windows запросит права администратора для сетевых адаптеров.
4. В настройках импортируйте **AmneziaWG 3.1 .conf**, выберите приложения и нажмите **Подключить**.

Не переносите один EXE отдельно: папки **_internal** и **bin** должны оставаться рядом. Собственный профиль и сервер в архив не входят.

**Переход с VLESS выполняется вручную:** нужен отдельный профиль AWG 3.1. Старый OTA-механизм не устанавливает эту версию. Сохранённые правила и настройки читаются из прежней папки `%LOCALAPPDATA%/VLESS-Boost`. Android в этом релизе не менялся и остаётся на VLESS/libbox.

## Проверки

32 автоматических теста, валидация конфигурации настоящим sing-box, UDP DNS-запрос через физический Wi-Fi с кириллическим именем, запуск пакетированного EXE, 80 переключений экранов и 10 циклов сворачивания/восстановления. Прохождение этих проверок не гарантирует доступность каждого пользовательского VPN-сервера.

В архив включены AmneziaWG 3.1.0, sing-box 1.11.15 и Qt runtime. SHA-256 архива опубликован отдельным файлом **SHA256SUMS.txt**.
