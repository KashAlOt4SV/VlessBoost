# Проверка Windows VEIL 2.0

Проверено 12 ноября 2026 на Windows, Python 3.11.4, Qt/PySide6 Essentials 6.12.0.

- 32 unittest-проверки: проходят. Включают импорт AWG 3.1, qCompress-ссылки, отказ от конфигурационных команд и многострочных инъекций, DPAPI, откат службы при ошибке, нативную валидацию конфигурации sing-box, отмену загрузок списков, очистку дочернего процесса через Windows Job Object и состояние Qt-окна.
- Старые сценарии test_parser.py и test_updater.py: проходят.
- `git diff --check` и компиляция Python: проходят.
- Нативное окно: 80 переключений с сохранением объектов четырёх экранов, 10 циклов maximize/minimize/restore, отзывчивость при фоне и завершение процесса. Результаты — native-check.json.
- Пакетированный EXE: тот же сценарий без UAC в тестовой сборке. Результаты — packaged-check.json. В последнем прогоне 80 переключений заняли 242 мс суммарно, максимальный интервал 16-мс UI-таймера — 18,85 мс. Эти числа относятся к этому компьютеру и этому прогону; тест не является записью GPU-кадров.
- Исправлена ошибка QtCore DLL: PyInstaller подхватывал несовместимый ICU из Poppler в PATH среды сборки. Сборочный файл исключает этот ICU и использует системный ABI Windows. Повторная чистая упаковка и запуск прошли без ручной замены DLL.
- Официальный MSI AmneziaWG 3.1.0 проверен через Authenticode и распакован локально; глобальная установка и подключение VPN при подготовке не выполнялись.

Реальные изображения интерфейса находятся в previews/. Подключение к пользовательскому серверу, RTT/пропускная способность реального VPN, фактическая маршрутизация приложений и смена физических сетей требуют рабочего AWG-профиля и отдельного сетевого прогона. Они здесь не проверялись. Android не менялся.

Конечная папка `dist/VEIL` дополнительно проверена копией конечного EXE с тем же Python-архивом и временно заменённым UAC-манифестом для запуска без повышения прав. Процесс завершился с кодом 0; 80 переключений — 119,54 мс, 10 циклов восстановления пройдены, максимальный интервал UI-таймера — 17,69 мс. Отчёт — final-packaged-check.json. Временный EXE удалён; основной VEIL.exe сохраняет requireAdministrator. Импортируемые символы собранных Qt DLL проверены отдельно.
