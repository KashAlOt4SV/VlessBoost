# Desktop preview — 2026-09-14

No release, tag or OTA manifest was published. Android unchanged.

## Findings and changes

- UI uses CustomTkinter 5.2.2, not Qt. The resize cover, WM_SETREDRAW and nested idle-event pumps caused partial painting. Removed the cover/native redraw suppression; local scrollbar adapter does not pump idle events while painting.
- The service catalog now paints visible entries on one canvas. All 26 presets, logos, selection callbacks, categories, search, cards/list, mouse wheel and keyboard navigation remain. Resize updates geometry without recreating service widgets. The scrollbar resets on filtering.
- Existing CTk polygon renderer reduces corner-glyph operations. Navigation restyles only affected sidebar buttons. Power image is updated only when it changes.
- Route counting, bounded log reads and normal disconnect run in workers. Worker completions go through a queue consumed on the GUI thread while work is pending.
- Core startup validates configuration before stopping an old instance and waits for a SOCKS5 greeting, with a deadline. Parent log handle closes after spawning. Disconnect stops the managed child, never another VPN client. Unknown executable paths are not treated as owned.
- A VLESS server hostname gets a bootstrap DNS rule before selected-site rules, preventing recursive resolution through itself. Transport, MTU, routing priorities and core version remain unchanged.
- Connection check can perform SOCKS5 + certificate-validated TLS + HTTP HEAD to a selected routed domain. It uses the active connection settings and discards results after a session change. Process-only configurations do not claim a verified tunnel. This is not a UDP packet-loss or Discord jitter measurement.

## Local measurements

Same Python 3.12 / Windows machine, isolated Settings defaults, original versus optimized source. Timings include Tk update processing, not a DWM frame-present measurement.

- Startup: 2592 → 1212 ms.
- First services page: 2837 → 206 ms.
- Repeated services page: 719–744 → 91 ms.
- Lists: 209 → 84 ms.
- Settings: 226 → 142 ms.
- Home: 232 → 166 ms.
- Resize sequence: 971–1906 → 300–372 ms.
- Native widget count: 918 → 419.
- Catalog construction handler: 890 → 19–23 ms.

These are local samples, not guaranteed latency targets. The stress test including several immediate page switches and a DPI change still recorded an event-loop gap up to 830 ms; ordinary transitions were measured separately above. DPI transitions remain an optimization opportunity.

## Validation

- 9 regression tests passed (`python -m pytest tests -q`).
- Installed sing-box 1.11.15 accepted the generated test configuration (`check`, no TUN started).
- UI smoke: filter after scrolling, service toggle, both views, minimize/restore, resize and 125% scaling completed without Tk callback exceptions; canvas identity persisted, all 26 presets remained.
- Cards and list visually inspected in an isolated source UI.
- PyInstaller EXE built; GUI subsystem, requireAdministrator manifest and embedded new modules verified. Archive CRC checked.
- Packaged EXE was not launched with elevation. Live TUN, long Discord sessions, UDP loss/jitter and Wi-Fi handover were not measured. Network-quality improvement requires a live comparison on the user's connection; no latency improvement is claimed from these tests.
